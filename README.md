# Puente

Tu Mac y tu PC con Windows, como si fueran una sola computadora: el mouse y el teclado pasan de una pantalla a otra,
copias en una y pegas en la otra, y te mandas archivos y links. Todo por tu red local, cifrado y sin cuentas.

## Descargar

- **Windows 10/11**: [Puente-Windows.exe](https://github.com/hectormonte1/puente-releases/releases/latest/download/Puente-Windows.exe)
- **Mac** (macOS 14 o superior, Intel o Apple Silicon): [Puente-Mac.zip](https://github.com/hectormonte1/puente-releases/releases/latest/download/Puente-Mac.zip)

Estos links siempre bajan la versión más nueva.

## Instalar

**Windows**: abre `Puente-Windows.exe`. Se instala solo (sin permisos de administrador) y queda en la barra junto al
reloj. Si Windows muestra "Windows protegió tu PC", elige **Más información → Ejecutar de todas formas**. Si pregunta
por el firewall, permite el acceso en redes privadas.

**Mac**: descomprime `Puente-Mac.zip` y arrastra **Puente** a Aplicaciones. Está notarizada por Apple, así que abre
sin avisos. Al abrirla, permite la red local y, para el mouse y el teclado, Accesibilidad.

Luego abre Puente en las dos computadoras (misma red Wi-Fi), elige **Conectar** y confirma que las dos muestran el
mismo código de 6 dígitos.
